# ElitePC frontend

React and Vite application for the ElitePC storefront and Admin interface.

```bash
cp .env.example .env
npm install
npm run dev
```

Set `VITE_API_URL` in `.env` to the Laravel API base URL. The default local value is `http://127.0.0.1:8000/api`.

Use `npm run build` for a production build and `npm run lint` for static checks.
